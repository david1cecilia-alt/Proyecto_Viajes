# Rutas & Ruedas · Portafolio de viajes

Web estática de un blog/portafolio de viajes: portada, sección "Sobre mí", galería de destinos y contacto.

Proyecto de **DAM 1º** (Lenguajes de Marcas), uno de mis primeros trabajos con HTML y CSS.

## Tecnologías

- HTML5 semántico (`header`, `nav`, `main`, `section`) con atributos de accesibilidad
- CSS3 con diseño adaptable a móvil
- Imágenes optimizadas en WebP/JPG

## Cómo verlo

No necesita instalación: clona el repo y abre `index.html` en el navegador.

```bash
git clone https://github.com/david1cecilia-alt/Proyecto_Viajes.git
```

## Estructura

```
index.html   → página única con todas las secciones
styles.css   → estilos
img/         → imágenes de los destinos
```
